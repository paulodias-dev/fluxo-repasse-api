# Apple Sign-In nativo
Rotas aditivas, login Google/web inalterados. Apple Identity Token RS256 com chave pública do endpoint fixo Apple, kid, issuer, audience (bundle iOS), iat/exp, nonce emitido por servidor e consumido sob lock compartilhado em cache (5 min); não aceitar e-mail/user_id/tenant do cliente. Cadastro exige e-mail verificado presente no token, termos, novo tenant; login subsequente por subject, sem vinculação automática por e-mail. Provedor desabilitado por padrão. APPLE_NATIVE_ENABLED=true e APPLE_NATIVE_AUDIENCE=bundle iOS real após configuração e validação. Cache compartilhado com locks (database/Redis), HTTPS e openssl necessários. Não armazenamos identity token ou authorization code. Não inclui troca de authorization code por refresh token, revogação Apple/fluxo de exclusão de conta nas lojas; requisitos de distribuição devem ser revisados antes de submissão. Testes feature escritos, ainda não executados; sem credenciais reais ou build iOS.
